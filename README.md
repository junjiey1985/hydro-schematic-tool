# 水系概化图工具

以地图为载体的水系数据管理与概化拓扑图绘制工具。

- **地图视图**：展示河流水系 / 水文站 / 雨量站 / 湖泊 SHP 数据，渲染河流与站点之间的拓扑关系（流向箭头、上下游高亮）；支持 SHP 导入、DEM 河网自动提取、手工绘制要素。
- **概化图视图**：根据 SHP 拓扑关系自动生成水系概化图；可拖动河段（线）、站点（点）、湖泊（面）自由调整，支持加点 / 加线 / 加面、重命名、删除、导出 SVG。
- **子流域划分（预报单元）**：按控制断面把流域切成若干预报单元——以水文站为出口（率定）、以汇流节点为出口（细化）、或以手工控制断面为出口（坝址/入汇口）；地图分色渲染单元面与出口断面，自动生成上下游嵌套关系、排水序、面积与雨量站权重，支持导出 GeoJSON / CSV / SHP，用于水文模型分区率定与逐段预报演算。
- **时序数据（率定输入）**：顶栏「时序数据」导入降雨 / 流量 / 蒸发 CSV（长表 / 宽表 / 单列，UTF-8 / GBK 容错，时段自动识别或聚合），自动统计缺测率与缺测区间；按预报单元核对"面雨量站是否齐备 + 出口站是否有实测流量"，给出可率定 / 借用参数结论；支持一键生成 3 年合成演示数据——**"实测"流量由真值参数跑一遍本工具的新安江模型生成**（OSSE），真值参数存档便于回收验证率定效果。
- **模型模拟（新安江三水源 + 马斯京根）**：三水源新安江模型（三层蒸散发 → 蓄满产流 → 自由水蓄水库分水源 → 三个线性水库汇流）逐预报单元演算区间产流，沿 `parent` 链用马斯京根分段连续演算把上游出流推到下游出口（KE 按出口间距自动估算，XE 可调）。顶栏「模型模拟」打开面板：单元参数矩阵表（可编辑、超区间标红）+ 模拟时段（起止 / 预热期）+ 一键运行，输出逐单元**实测 vs 模拟过程线**、NSE / R² / KGE / RMSE / PBIAS / 峰现时间误差（多场洪峰中位数）、洪峰明细表与**水量平衡表**（P = E + q + Δ蓄量，闭合误差为机器精度）。参数集按单元持久化，支持一键恢复默认。

## 快速开始

```bash
# 1) 后端依赖（首次）
C:/Users/giser/.workbuddy/binaries/python/envs/default/Scripts/python.exe -m pip install fastapi uvicorn numpy scipy shapely networkx pyproj pyshp

# 2) 前端依赖与构建（首次）
cd frontend
npm install
npm run build

# 3) 启动（单端口，前端由后端托管）
cd ../backend
python run.py --host 127.0.0.1 --port 8013
```

浏览器打开 <http://127.0.0.1:8013>，左侧面板点击「导入示例流域」即可一键体验全流程（合成 DEM → 河网提取 → 拓扑 → 概化图）。

开发模式：`backend: python run.py --port 8000` + `frontend: npm run dev`（Vite 代理 /api）。

## 数据来源（三种）

1. **导入 SHP**：选择类型（河流/水文站/雨量站/湖泊/边界），上传 `.shp/.shx/.dbf/.prj`；自动识别投影并转为 WGS84，中文属性 GBK/UTF-8 自动容错。
2. **DEM 生成**：上传 GeoTIFF 或 ESRI ASCII Grid，设置汇流阈值后一键提取河网（填洼 → D8 → 汇流累积 → 矢量化），附晕渲底图。
3. **手工绘制**：地图上绘点（站点）、绘线（河流）、绘面（湖泊），自动保存到目标图层。

## 地图底图与坐标

地图底图默认为**无底图**（可在右上角切换「高德地图 / 高德影像 / 无底图」，默认关闭高程晕渲）。国内合规底图为 GCJ-02（火星坐标），与本项目 WGS-84 数据相差约 500 m——工具已内置自动纠偏（`frontend/src/gcj.js`），数据落库仍为 WGS-84，显示时自动对齐底图，河流、站点与真实位置一致。

底图密钥从 `frontend/.env.local` 读取（不会提交到版本库，模板见 `.env.example`）：

```
VITE_AMAP_KEY=你的高德 Web 端 Key
VITE_AMAP_SECURITY_CODE=对应的安全密钥
```

在高德开放平台（console.amap.com）创建「Web端(JS API)」类型 Key 即可；未配置时高德底图仍可加载。正式部署建议在高德控制台为该 Key 配置 Referer 白名单。

## 子流域划分

顶栏「子流域划分」打开弹窗，选择划分依据后一键生成预报单元：

- **水文站模式**：以已挂接水文站为单元出口，输出面积即为率定控制面积（如堵河：竹山 8211 km² → 黄龙滩 2980 km² → 出口 526 km²）；
- **汇流节点模式**：以拓扑汇流点为出口，把流域细化为任意粒度的预报分区；
- **手工控制断面模式**：在地图上绘制控制断面点（水库坝址、支流入汇口等）作为单元出口。

划分结果在地图上按单元分色渲染（含出口三角与 编号/面积 标注），侧栏「预报单元」列表支持点击定位、改名；可导出 GeoJSON（边界+出口）、CSV（率定参数表）、SHP(zip) 供模型前后处理使用。

概化图视图联动：「概化图编辑」面板中的「河段按预报单元着色」开关，让同一预报单元的河段与流向箭头显示同一种颜色（与地图单元面同配色），并内嵌单元色标图例，便于对照预报分区检查河网结构。在概化图视图下，点击侧栏「预报单元」列表行（或图例中的单元行）可聚焦该单元：河段加粗、其余淡化，视图自动定位到该单元的河段范围；再点一次退出聚焦并回到适配视图。地图视图下点击列表行则仍是在地图上定位选中该单元面。

## 使用提示

- 构建拓扑前建议先准备好河流图层；有 DEM 时流向判定更可靠。
- 概化图支持拖动节点/河段/站点/湖泊；「按新参数重排」保留已拖动位置，可按布局方向与间距微调。
- 所有接口见 <http://127.0.0.1:8013/docs>。
